Kasir belum tersambung ke Supabase

  1. Buat project di Supabase, lalu jalankan isi file supabase-kasir.sql di SQL Editor.
  2. Di Authentication, matikan Confirm email.
  3. Buka kasir.html, isi SUPABASE_URL dan SUPABASE_ANON_KEY di bagian paling atas.
  4. Upload ulang ke GitHub, lalu daftar. Akun pertama otomatis jadi admin.
